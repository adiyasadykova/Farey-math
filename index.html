Primitive vs Non-Primitive

A Pythagorean triple is primitive if gcd(x, y, z) = 1.

From Euclid's formula, a triple is primitive if and only if:

  • gcd(m, n) = 1 (m and n are coprime)
  • m and n have opposite parity (one even, one odd)
  • m > n > 0

Insights

Connection: Both structures enumerate all positive reduced fractions.

Farey: Organized by order n, contains all fractions a/b where gcd(a,b)=1 and b≤n.

Stern-Brocot: Generated recursively via the mediant property: between a/b and c/d lies (a+c)/(b+d).

Pythagorean Connection: Each fraction m/n generates a triple; primitive triples arise only when gcd(m,n)=1 and m,n have opposite parity.
